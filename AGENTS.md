## Escopo local

Este repositório reúne site público, área de membros e o Admin, workspace útil para a equipe organizar o trabalho. Demandas, responsáveis, prazos e acesso aos materiais orientam a compreensão do produto. Rotas auxiliares documentadas no README não definem prioridades por si.

Consulte [README.md](README.md) para estrutura e publicação. O snapshot de 04/09 registra deploy automático a cada push na main. Em uma tarefa apenas documental, não executar publicação ou deploy como etapa de validação.

O banco do Admin é distinto do banco do Sistema Black. Não transportar instruções, tabelas ou decisões de um para o outro por semelhança de nome.

A instrução explícita da sessão define a ação autorizada. Contexto, README, acesso administrativo e planos antigos não autorizam automaticamente executar uma mudança. Não copiar o conteúdo privado da equipe para um repositório público. Este arquivo orienta a leitura; a hierarquia e as decisões são mantidas na fonte comum.
